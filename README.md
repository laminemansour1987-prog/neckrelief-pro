# LM Plomberie 69 — Site vitrine

Site vitrine statique (HTML/CSS/JS) pour LM Plomberie 69, plombier-chauffagiste à Rillieux-la-Pape.

## Pages

- `index.html` — Accueil
- `services.html` — Plomberie, chauffage, climatisation, traitement de l'eau
- `a-propos.html` — Présentation de l'entreprise
- `contact.html` — Formulaire de contact et coordonnées

## Développement

Aucune dépendance ni build : ouvrez `index.html` dans un navigateur, ou servez le dossier avec un serveur statique, par exemple :

```
python3 -m http.server 8000
```
